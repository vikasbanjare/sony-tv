# repos/

Clones of the projects in `../config/repos.tsv`, for reading. Nothing in here is committed
(see `.gitignore`), and nothing in here is installed on the TV.

```sh
sh scripts/clone-repos.sh
```

ArgyllCMS has no GitHub repository (the address in the original plan does not exist).
Get it from https://www.argyllcms.com/ or with `brew install argyll-cms`, and only if you have a meter.
